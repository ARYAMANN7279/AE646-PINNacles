\section*{Individual Contribution Statement}

\textbf{Team member: Aryamann Srivastava}

\begin{itemize}
  \item \textbf{Problem formulation and literature review}: Identified the 2D Darcy flow benchmark in PDEBench as the project focus; reviewed the FNO paper \cite{li2021fno} and PDEBench paper \cite{takamoto2022pdebench}.

  \item \textbf{Data pipeline}: Implemented \texttt{src/download\_data.py} and \texttt{src/preprocess.py} for downloading and preprocessing PDEBench data; designed the 8\,000/900/200 train/val/test split.

\section*{AI Tool Use Declaration}

In accordance with the AE646 course policy on generative AI tools, I declare the following use of AI assistance during this project:

\begin{enumerate}
  \item \textbf{Code debugging}: Claude Code (Anthropic) was used to identify and fix a GPU timing bug in the component profiling script. Specifically, the issue was that \texttt{time.perf\_counter()} measured dispatch time rather than execution time for asynchronous GPU operations; the fix (\texttt{torch.cuda.synchronize()} before each timer call) was suggested by the AI assistant. All code was reviewed, understood, and accepted by me before being committed.

  \item \textbf{LaTeX formatting}: Claude Code assisted with LaTeX document structure and table formatting for the proposal and reports. All technical content, numbers, and scientific claims are my own.

  \item \textbf{Presentation slides}: Claude Code assisted with Python code to programmatically build the Stage 1 PPTX presentation using \texttt{python-pptx}. The technical content of every slide was written by me.

  \item \textbf{No AI-generated results}: All numerical results in this report are from experiments I ran on real hardware. No results were generated or hallucinated by AI tools.
\end{enumerate}
