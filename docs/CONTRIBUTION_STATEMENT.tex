\section*{Individual Contribution Statement}

\textbf{Team member: Aryamann Srivastava}

\begin{itemize}
  \item \textbf{Problem formulation and literature review}: Identified the 2D Darcy flow benchmark in PDEBench as the project focus; reviewed the FNO paper \cite{li2021fno} and PDEBench paper \cite{takamoto2022pdebench}.

  \item \textbf{Data pipeline}: Implemented \texttt{src/download\_data.py} and \texttt{src/preprocess.py} for downloading and preprocessing PDEBench data; designed the 900/100/200 train/val/test split (a 1\,000-sample train/val pool plus 200 held-out test samples, drawn with a fixed seed from PDEBench's 10\,000-sample archive).

  \item \textbf{Model implementation}: Implemented \texttt{MLPBaseline}, \texttt{SpectralConv2d}, and \texttt{FNO2d} in \texttt{src/models.py}; verified correctness against the reference FNO codebase.

  \item \textbf{Training}: Implemented \texttt{src/train.py} with Adam optimiser and cosine LR annealing, retaining the checkpoint with the lowest validation relative-$L_2$ error; ran all three training runs (FNO original, MLP, FNO improved) on the lab GPU VM.

  \item \textbf{Evaluation}: Implemented \texttt{src/evaluate.py}, \texttt{src/superres\_eval.py}, and \texttt{src/benchmark\_speed.py}; collected all quantitative results.

  \item \textbf{Component profiling}: Designed and implemented \texttt{src/benchmark\_components.py} with correct GPU synchronisation to measure per-layer execution time.

  \item \textbf{Figure generation}: Implemented \texttt{src/generate\_figures.py}; produced all six report figures from stored JSON results.

  \item \textbf{Reports and presentations}: Wrote Stage 1 proposal (\texttt{PROPOSAL.tex}), Stage 1 presentation (10 slides), Stage 2 interim report (\texttt{INTERIM\_REPORT.tex}), the Stage 3 final presentation (\texttt{PINNacles\_Stage3\_FinalPresentation}), and this final report (\texttt{FINAL\_REPORT.tex}).
\end{itemize}

Team PINNacles was formed with four members at the proposal stage (Aryamann Srivastava, Varun Sathaye, Atishay Jain, Vedant Shekhar Tiwari). The implementation, experiments, figures, and reports contained in this repository were carried out by Aryamann Srivastava, whose individual contributions are listed above.

\section*{AI Tool Use Declaration}

In accordance with the AE646 course policy on generative AI tools, I declare the following use of AI assistance during this project:

\begin{enumerate}
  \item \textbf{Code debugging}: Claude Code (Anthropic) was used to identify and fix a GPU timing bug in the component profiling script. The issue was that \texttt{time.perf\_counter()} measured dispatch time rather than execution time for asynchronous GPU operations; the fix (a device-synchronisation call before every timer read --- \texttt{torch.cuda.synchronize} on CUDA, \texttt{torch.mps.synchronize} on Apple Silicon) was suggested by the AI assistant. All code was reviewed, understood, and accepted by me before being committed.

  \item \textbf{Report drafting and consistency checking}: Claude Code assisted with LaTeX structure and table formatting, with drafting and editing report prose, and with cross-checking the numbers quoted in the reports against the stored results files (\texttt{results/*/eval\_metrics.json}, \texttt{benchmark\_*.json}) and the training configs. Every number originates from my own experiments; all scientific claims and their interpretation are my own and were verified by me.

  \item \textbf{Presentation slides}: Claude Code assisted with Python code to programmatically build the Stage 1 PPTX presentation using \texttt{python-pptx}. The technical content of every slide was written by me.

  \item \textbf{No AI-generated results}: All numerical results in this report are from experiments I ran on real hardware. No results were generated or hallucinated by AI tools.
\end{enumerate}
