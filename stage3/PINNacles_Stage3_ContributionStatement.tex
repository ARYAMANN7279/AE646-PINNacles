\section*{Individual Contribution Statement}

\textbf{Team member: Aryamann Srivastava}

\begin{itemize}
  \item \textbf{Problem formulation and literature review}: Identified the 2D Darcy flow benchmark in PDEBench as the project focus; reviewed the FNO paper \cite{li2021fno} and PDEBench paper \cite{takamoto2022pdebench}.

  \item \textbf{Data pipeline}: Implemented \texttt{src/download\_data.py} and \texttt{src/preprocess.py} for downloading and preprocessing PDEBench data; designed the 900/100/200 train/val/test split (a 1\,000-sample train/val pool plus 200 held-out test samples, drawn with a fixed seed from PDEBench's 10\,000-sample archive).

  \item \textbf{Model implementation}: Implemented \texttt{MLPBaseline}, \texttt{SpectralConv2d}, and \texttt{FNO2d} in \texttt{src/models.py}; verified correctness against the reference FNO codebase.

  \item \textbf{Training}: Implemented \texttt{src/train.py} with AdamW and a cosine learning-rate schedule, retaining the checkpoint with the lowest validation relative-$L_2$ error; ran all three training runs (FNO original, MLP, FNO improved) on the lab GPU VM.

  \item \textbf{Evaluation}: Implemented \texttt{src/evaluate.py}, \texttt{src/superres\_eval.py}, and \texttt{src/benchmark\_speed.py}; collected all quantitative results.

  \item \textbf{Component profiling}: Designed and implemented \texttt{src/benchmark\_components.py} with correct GPU synchronisation to measure per-layer execution time.

  \item \textbf{Analysis and ablations}: Implemented \texttt{src/eda.py} (dataset analysis and the error-vs-geometry study), \texttt{src/ablation\_mlp.py} (depth/optimiser) and \texttt{src/ablation\_preprocess.py} (preprocessing, 3 seeds); ran them on the lab GPU workstation.

  \item \textbf{Stage 3 optimisation study}: Designed the Stage 3 experiment matrix and implemented \texttt{src/stage3\_train.py} (fixed-budget training with recipe options, D4 augmentation and test-time symmetrisation, multi-resolution evaluation), \texttt{src/run\_jobs.py} (job queue), \texttt{src/data\_cache.py}, the vectorised finite-volume solver \texttt{src/solvers.py} with its calibration and timing (\texttt{src/solver\_vs\_fno.py}), \texttt{src/stage3\_latency.py}, \texttt{src/stage3\_diagnostics.py}, and \texttt{src/stage3\_aggregate.py}/\texttt{stage3\_figures.py}; ran the 142 runs (recipe ablation, architecture sweeps, data scaling, resolution study, five-seed final models) on the lab GPU workstation.

  \item \textbf{Figure generation}: Implemented \texttt{src/generate\_figures.py}; produced the report figures from stored JSON results.

  \item \textbf{Reports and presentations}: Wrote Stage 1 proposal (\texttt{stage1/PINNacles\_Stage1\_Proposal.tex}), Stage 1 presentation (10 slides), Stage 2 interim report, presentation and code package (\texttt{stage2/}, including a single notebook that combines the pipeline scripts), the Stage 3 final presentation (\texttt{stage3/PINNacles\_Stage3\_FinalPresentation}), and this final report (\texttt{stage3/PINNacles\_Stage3\_FinalReport.tex}).
\end{itemize}

Team PINNacles was formed with four members at the proposal stage (Aryamann Srivastava, Varun Sathaye, Atishay Jain, Vedant Shekhar Tiwari). The implementation, experiments, figures, and reports contained in this repository were carried out by Aryamann Srivastava, whose individual contributions are listed above.

\section*{AI Tool Use Declaration}

In accordance with the AE646 course policy on generative AI tools, I declare the following use of AI assistance during this project:

\begin{enumerate}
  \item \textbf{Coding assistance and debugging}: Claude Code (Anthropic) assisted with writing and debugging project code, including the data, training and evaluation scripts, the analysis and ablation scripts, and the notebook that combines them. One example is the GPU timing fix in the component profiling script: \texttt{time.perf\_counter()} measured dispatch time rather than execution time for asynchronous GPU operations, and the fix (a device-synchronisation call before every timer read --- \texttt{torch.cuda.synchronize} on CUDA, \texttt{torch.mps.synchronize} on Apple Silicon) was suggested by the AI assistant. All code was reviewed and accepted by me before being committed.

  \item \textbf{Running experiments and checking results}: At my direction, Claude Code executed the scripts on the lab GPU workstation (training, ablations, the notebook run) and cross-checked every number quoted in the reports, slides and README against the stored results files and training configs. This surfaced several documentation errors that were then corrected (for example the training-loss and learning-rate-schedule descriptions, the dataset split, and rounded percentage figures).

  \item \textbf{Report and slide drafting}: Claude Code assisted with LaTeX structure and table formatting, with drafting and editing report text, and with Python (\texttt{python-pptx}) and Beamer code to build the Stage 1, Stage 2 and Stage 3 presentations. The technical content, numbers and interpretation were reviewed and verified by me.

  \item \textbf{Stage 3 experiments}: Claude Code also proposed and implemented the Stage 3 experiment design and scripts listed above, launched the runs on the lab workstation at my direction, and identified that the Stage 2 training recipe (MSE loss, a learning-rate schedule that restarted every 200 steps) and the Stage 2 solver-timing reference were sub-optimal; the Stage 2 speed-up claim was withdrawn in the final report as a result. I reviewed the design, the results and the conclusions.

  \item \textbf{No AI-generated results}: All numerical results in this report come from real experiments run on real data and hardware. No results were generated or invented by AI tools.
\end{enumerate}
